## 三条买之前容易忽略的限制

这几条在产品页上都不显眼，但直接影响你的使用体验和选型。

**第一，流量用完不会停机，只会降速。** 帮助文档里写独享版流量“不限”，产品页又给每档标了“月高速流量”，比如基础增强版是200GB，看着矛盾，实际是这么回事：每月的高速流量额度用完后，带宽降到1Mbps，网站照常访问，不额外收费，下个计费月恢复。1Mbps看文字内容没问题，图片多的页面会明显变慢。对博客和小站来说，这基本等于流量随便用；图片站和下载站就要掂量一下自己的月流量了。

**第二，海外机房装不了Windows。** 香港、美国、新加坡机房的增强版独享主机不支持切换为Windows系统，只能用Linux（PHP + MySQL）。也就是说，跑ASP、ASP.NET程序的网站必须选内地机房，而内地机房又需要备案——两条加在一起，ASP老站基本没有免备案这条路。另外，部分主机由于硬件和机房位置的限制，购买后也不支持更换操作系统，下单时就要选对。

**第三，买完不是马上能用，要先设三组密码。** 阿里云不会给初始密码，主机开通后你要自己设置管理控制台密码、FTP密码和数据库密码，规则是8–20位、必须包含大小写字母、数字、特殊字符中的任意三项。三组都设好，再把域名绑定到主机、解析生效、备案状态正常，网站才能真正访问。

## 能跑什么程序，支持什么环境

选系统前先看你网站程序是什么语言：Linux主机对应PHP系，Windows主机对应ASP/ASP.NET系。

- **Linux**：PHP + MySQL/SQLite。WordPress、Z-Blog、Discuz、织梦CMS这类主流PHP程序都能装，阿里云官方文档里就有安装WordPress和Z-Blog的完整教程。增强版Linux主机可以在控制台切换PHP版本、开关PHP函数，还能配置Nginx文件。

## 常见问题

**阿里云虚拟主机需要备案吗？**
内地机房需要。域名要完成ICP备案、状态正常后才能访问；香港、美国、新加坡机房不用备案。

**月流量用完了网站会关吗？**
不会。独享增强版的处理方式是降速不关站：带宽降到1Mbps，网站照常打开，也不额外收费，下个计费月恢复。

**能装WordPress吗？**
能。选Linux系统就行，官方文档有从上传程序到安装完成的完整教程，Z-Blog同理。

**虚拟主机和云服务器ECS选哪个？**
不想碰服务器运维，选虚拟主机：环境预装好、图形化面板操作，成本也低。需要自定义环境、跑特殊应用再上ECS，代价是装环境和日常维护都得自己来。

**买完还能换机房吗？**
能，控制台支持更改主机机房。但部分主机不支持更换操作系统，海外机房的增强版独享主机也用不了Windows，这两件事在购买前就要想清楚。
